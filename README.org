#+title: Marlin MyGo — High-Performance, Modular Agent UI Engine & Plugin Ecosystem
#+filetags: :tao3k:marlin:mygo:ui:grpc:plugins:wasm:

=marlin-mygo= is a *high-performance, modular, hot-pluggable UI engine and
plugin ecosystem* for [[https://github.com/tao3k/marlin-agent-core][Marlin Agent CORE]]
(Rust Authority Kernel + Gerbil Scheme Policy Engine), built on
[[https://github.com/egoist/mygo][MyGo]] (pure Go, zero cgo on desktop, native
Metal / Direct3D 11 / OpenGL GPU rendering, isolated OS WebViews, and native
iOS/Android bridges).

* Why Marlin MyGo?

- *120Hz Native GPU Performance (Zero CGO)*: Pure-Go native GPU rendering backed
  by a flat BFS UI-IR arena with dual Merkle incremental diffing (=0 allocs=),
  lock-free Copy-on-Write event fan-out with power-of-two coalescing rings,
  compiled Meow/Hydra =KeyTrie= lookup, and a Fenwick BIT virtual height index
  built for 100k+ row streaming transcripts.
- *Modular & Extensible by Construction*: Every workbench surface is composed
  of hot-pluggable slots (=single= / =list= / =keyed=) with automatic =host.*=
  fallback, unified multi-machine federated gRPC sidebar switching, and
  single-source Protobuf + =BoundedSchema= contracts that derive Go stubs,
  TypeScript SDK types, and zero-WebView GPU forms without drift.
- *Open, Sandboxed Plugin Ecosystem (Marketplace)*: Downstream developers can
  build hot-pluggable panels in *TypeScript* (=webview-untrusted= via
  =@tao3k/marlin-panel-sdk=), *Go 1.27 WASI Reactors* (=wasm-ui-ir= & zero-JSON
  binary =DrawList= rendered directly on the host GPU via =wazero=), or
  *Declarative Packs* (App Store–safe over-the-air themes, layouts, and
  overlays), distributed as deterministic Ed25519-signed =.marlinpkg= archives.
- *Formally Verified Security Boundaries*: Six core isolation invariants
  (restricted =approval.gate= protection, =CallerPage == Host= WebView origin
  pinning, unforgeable WASM module proxy binding, monotonic generation
  revocation, circuit-breaker fallback, and one-shot Rust =GateReceipt= device
  writes) are formally challenged in Quint with 7 adversarial negative controls,
  2,000-step Go adversarial state-machine property tests, and 8 Go fuzzers.

* Quick Start

#+begin_src shell
# Enter reproducible Go 1.27.3 + Buf + Protoc + Bun environment
direnv allow

# Validate Protobuf contracts, Quint formal security gate, tests, race detector & build
just check

# Regenerate Go gRPC stubs + zero-drift TypeScript wire types
just proto-gen

# Run native Go fuzz smoke tests across schema, drawlist, protocol, arena & input boundaries
just fuzz-smoke

# Scaffold, sign, and verify a new Marketplace plugin (ts | go-wasm | declarative)
just init-plugin acme.sprint-board ts workbench.main ./tmp-plugin
CGO_ENABLED=0 go run ./cmd/marlin-mygo-tool keygen -out ./tmp-keys/acme
CGO_ENABLED=0 go run ./cmd/marlin-mygo-tool pack -dir ./tmp-plugin -publisher acme.dev -key ./tmp-keys/acme.key -out ./acme-board.marlinpkg
CGO_ENABLED=0 go run ./cmd/marlin-mygo-tool verify -pkg ./acme-board.marlinpkg -publisher acme.dev -pub ./tmp-keys/acme.pub

# Enforce strict Go + TypeScript latency, byte, and zero-allocation performance gate
just perf-gate

# Run 5-test real cross-process Rust <-> Go E2E suite (TLS 1.3, WASI Reactor, Turso crash-restart, SIGKILL self-healing)
CGO_ENABLED=0 go run ./cmd/marlin-mygo-tool e2e-rust -core /path/to/marlin-agent-core

# Host signed example Marketplace catalog locally & run plugin author hot-reload dev loop
CGO_ENABLED=0 go run ./cmd/marlin-mygo-tool build-examples -out ./dist/marketplace
just serve-catalog ./dist/marketplace 127.0.0.1:8787
just dev-plugin ./examples/plugins/go-graph-inspector-reactor

# Launch zero-cgo GPU workbench (standalone, signed Marketplace catalog, live dev-plugin, OR auto-healing Rust sidecar)
CGO_ENABLED=0 go run ./cmd/marlin-app
CGO_ENABLED=0 go run ./cmd/marlin-app -catalog-url http://127.0.0.1:8787 -catalog-pub ./dist/marketplace/publisher.pub
CGO_ENABLED=0 go run ./cmd/marlin-app -dev-plugin ./examples/plugins/go-graph-inspector-reactor
CGO_ENABLED=0 go run ./cmd/marlin-app -sidecar /path/to/marlin-mygo-host -real-session -turso ./session.turso
#+end_src
