#+title: Marlin MyGo — High-Performance, Modular Agent UI Engine & Plugin Ecosystem
#+filetags: :tao3k:marlin:mygo:ui:grpc:plugins:wasm:

=marlin-mygo= is a *high-performance, modular, hot-pluggable UI engine and
plugin ecosystem* for [[https://github.com/tao3k/marlin-agent-core][Marlin Agent CORE]]
(Rust Authority Kernel + Gerbil Scheme Policy Engine), built on
[[https://github.com/egoist/mygo][MyGo]] (pure Go, zero cgo on desktop, native
Metal / Direct3D 11 / OpenGL GPU rendering, isolated OS WebViews, and native
iOS/Android bridges).

* Why Marlin MyGo?

- *120Hz Native GPU Performance (Zero CGO)*: Pure-Go native GPU rendering backed
  by a flat BFS UI-IR arena with dual Merkle incremental diffing (=0 allocs=),
  lock-free Copy-on-Write event fan-out with power-of-two coalescing rings,
  compiled Meow/Hydra =KeyTrie= lookup, and a Fenwick BIT virtual height index
  built for 100k+ row streaming transcripts.
- *Modular & Extensible by Construction*: Every workbench surface is composed
  of hot-pluggable slots (=single= / =list= / =keyed=) with automatic =host.*=
  fallback, unified multi-machine federated gRPC sidebar switching, and
  single-source Protobuf + =BoundedSchema= contracts that derive Go stubs,
  TypeScript SDK types, and zero-WebView GPU forms without drift.
- *Open, Sandboxed Plugin Ecosystem (Marketplace & Emacs-Grade Lazy Loader)*:
  Downstream developers and coding LLMs can build hot-pluggable panels in
  *TypeScript* (=webview-untrusted= via =defineMarlinPanel= in
  =@tao3k/marlin-panel-sdk=), *Go 1.27 WASI Reactors* (=wasm-ui-ir= & zero-JSON
  binary =DrawList= via zero-=unsafe= =uiir.RenderResult= on =wazero=), or
  *Declarative Packs* (App Store–safe over-the-air themes, layouts, and
  overlays). Installed plugins are managed declaratively via
  =marlin-plugins.toml= with *zero startup RAM* for 100+ dormant plugins,
  lock-free COW hook/command dispatch (=0 allocs=), singleflight on-demand
  waking, O(1) intrusive LRU working-set eviction, idle memory reclamation, and
  1-command security-certified =doctor= / =publish= into Ed25519-signed
  =catalog.json= registries.
- *Rust-Cargo-Style Compile-Time Feature Pruning & Tier-0 Governance*: Optional
  interaction paradigms (=features/chatroom= Multi-Role Agent Room,
  =features/compare= Parallel Model Arena & Branch Tree, and =features/canvas=
  Live Artifact Canvas) are strictly gated by Go build tags (=marlin_minimal=,
  =marlin_feat_*=, =marlin_full=) with zero dead code in minimal Desktop or Web
  WASM builds (=just check-feature-pruning=), governed by the Tier-0 UI
  Governance Console (=SPC G=), ESC-unbypassable =engine/promptgate= human
  approval modals, and fail-closed RBAC where AI agents never hold
  =CanApproveGates=.
- *Power-Loss Durability & Reconnect Continuity*: Unsent drafts, =@= context
  mentions, pending offline outbox turns, and =LastEventID= stream cursors are
  persisted atomically via =0600= + =fsync= + =os.Rename= on Desktop and
  =window.localStorage= on Web WASM (=engine/resilience= +
  =grpcwire.ContinuityCoordinator=), with automatic exponential-backoff
  reconnect, replay deduplication, and FIFO idempotent outbox draining across
  Chat, Mobile Companion, Agent Room, Compare, and Canvas.
- *Formally Verified Security Boundaries*: Ten core isolation invariants
  (restricted =approval.gate= protection, Ed25519 release integrity,
  =CallerPage == Host= WebView origin pinning + MyGo WebKit =ContentRules=
  egress blocking, =read_scopes= isolation, one-shot Rust =GateReceipt= device
  writes, circuit-breaker fallback, lockfile =pinned_sha256= lazy wake,
  dormant slot isolation, bounded LRU working-set cap, and anti-silent upgrade
  privilege escalation confirmation) are formally challenged in Quint with
  *11 adversarial negative controls*, *5,000+ combined randomized adversarial
  state-machine steps* across =pluginhost= and =marketplace=, and *10 Go fuzzers*.

* Quick Start

#+begin_src shell
# Enter reproducible Go 1.27.3 + Buf + Protoc + Bun environment
direnv allow

# Validate Protobuf contracts, Quint formal security gate, tests, race detector & build
just check

# Regenerate Go gRPC stubs + zero-drift TypeScript wire types
just proto-gen

# Run native Go fuzz smoke tests across schema, drawlist, protocol, arena & input boundaries
just fuzz-smoke

# Scaffold, audit (doctor), certify-and-publish (1 command) a new Marketplace plugin (ts | go-wasm | declarative)
just init-plugin acme.sprint-board ts workbench.main ./tmp-plugin
just doctor ./tmp-plugin
CGO_ENABLED=0 go run ./cmd/marlin-mygo-tool keygen -out ./tmp-keys/acme
just publish ./tmp-plugin acme.dev ./tmp-keys/acme.key ./tmp-keys/acme.pub ./dist/marketplace

# Verify Rust-Cargo-style compile-time feature pruning across Desktop & Web WASM
just check-feature-pruning
just build-core
just build-features "marlin_feat_chatroom"
just build-full

# Enforce strict Go + TypeScript latency, byte, and zero-allocation performance gate
just perf-gate

# Run 5-test real cross-process Rust <-> Go E2E suite (TLS 1.3, WASI Reactor, Turso crash-restart, SIGKILL self-healing)
CGO_ENABLED=0 go run ./cmd/marlin-mygo-tool e2e-rust -core /path/to/marlin-agent-core

# Host signed example Marketplace catalog locally & run plugin author hot-reload dev loop
CGO_ENABLED=0 go run ./cmd/marlin-mygo-tool build-examples -out ./dist/marketplace
just serve-catalog ./dist/marketplace 127.0.0.1:8787
just dev-plugin ./examples/plugins/go-graph-inspector-reactor

# Launch zero-cgo GPU workbench (standalone, signed Marketplace + persistent Emacs lazy profile, live dev-plugin, OR auto-healing Rust sidecar)
CGO_ENABLED=0 go run ./cmd/marlin-app
CGO_ENABLED=0 go run ./cmd/marlin-app -catalog-url http://127.0.0.1:8787 -catalog-pub ./dist/marketplace/publisher.pub -plugins-profile ./marlin-plugins.toml
CGO_ENABLED=0 go run ./cmd/marlin-app -dev-plugin ./examples/plugins/go-graph-inspector-reactor
CGO_ENABLED=0 go run ./cmd/marlin-app -sidecar /path/to/marlin-mygo-host -real-session -turso ./session.turso
#+end_src
