#+title: 03 — Target Separation, C ABI Native Modules, and Scheme Profile Overlays
#+filetags: :tao3k:marlin:mygo:mobile:ios:android:scheme:

* Separation Principle

Complex agent capabilities live in the backend and OS-native target adapters;
the UI shell remains a thin, uniform projection over =marlin.*.v1= gRPC.

- *Shared Base Profile (Gerbil Scheme / Yuanxu POO)*: owns cross-device user
  intent, Org archival rules, memory projection, approval governance, and
  host-neutral UI IR.
- *Target Profile Overlays (=+macos=, =+linux=, =+ios=, =+android=, =+remote=)*:
  select platform-specific native capabilities compiled into each target binary
  and bind governance policies (=allow= / =ask= / =deny=) per capability.

* Transport Parity Across Targets

| Target | Local Host Packaging | Native Protocol Layer | Remote Machines |
|--------+----------------------+-----------------------+-----------------|
| Desktop (macOS / Linux / Windows) | Spawned =marlin-host= sidecar over loopback HTTP/2 + one-time env token | Go OS APIs + optional Rust/Swift =//mygo:native= | Sidebar =TargetRegistry= (=ModeRemoteGRPC=) |
| iOS (=.ipa=) | Embedded Rust/Gambit-C =.xcframework= via C ABI (no =fork/exec= sidecar) | Swift =//mygo:native= (=PhotoKit=, =Vision=, =Contacts=, =EventKit=, =AppIntents=, =ActivityKit=) + =ios.extensions= (=ShareExtension.appex=) | Same sidebar =TargetRegistry= (=ModeRemoteGRPC=) |
| Android (=.apk= / =.aab=) | Embedded NDK =.so= (or =extractNativeLibs= executable with 16 KB page alignment) | Kotlin =//mygo:native= (=MediaStore=, =ContactsContract=, =Intents=, =AccessibilityService=) | Same sidebar =TargetRegistry= (=ModeRemoteGRPC=) |

* Gated Device Invocation Flow

1. Client target starts up and registers OS-authorized capabilities via
   =DeviceBridgeService.RegisterDeviceNode= and =OpenDeviceChannel=.
2. Host Scheme Profile Overlay evaluates whether a requested device capability
   requires human approval.
3. For any mutating capability (=read_only == false=), =pkg/device.Bridge=
   refuses execution unless the host invocation carries a valid Rust-minted
   =GateReceipt=.
4. Proactive user triggers (e.g., iOS Back-Tap Shortcut → Screenshot → Swift
   =AppIntent=, or Share Extension App Group queue) push bounded metadata plus
   =ArtifactRef= digests via =DeviceBridgeService.IngestCapture=.
